# OMNI — صندوق الأدوات اليومي

نسخة أولية لتطبيق Android مبني باستخدام Flutter. الواجهة عربية RTL، وتحتوي على 20 أداة مع بحث وتصنيفات ومفضلة ووضع ليلي/نهاري.

## الأدوات الموجودة

1. الحاسبة.
2. قائمة المهام (حفظ محلي).
3. لعبة تخمين الرقم.
4. مولّد كلمات المرور (محلي).
5. دليل تجهيز بوت تيليجرام.
6. محول العملات بسعر صرف يدوي.
7. مؤقت التركيز.
8. دفتر الملاحظات (حفظ محلي).
9. عداد الكلمات والحروف.
10. حجر ورقة مقص.
11. مستعرض الملفات.
12. سجل أسعار يدوي.
13. لعبة الثعبان.
14. الطقس عبر Open-Meteo (إنترنت).
15. سجل المصروفات (حفظ محلي).
16. مختصر الروابط عبر is.gd (إنترنت وخدمة خارجية).
17. اختبار معلومات عامة.
18. قارئ PDF.
19. استوديو إنشاء QR ومسح QR/الباركود.
20. منشئ قالب HTML.

**بديل فكرة الذكاء الاصطناعي في الإصدار الأول:** استوديو QR والباركود. إنشاء رموز QR محلياً، ومسح الرموز باستخدام كاميرا الجهاز.

## طريقة بناء APK من GitHub (بدون كمبيوتر قوي)

1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد باسم `omni`.
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build OMNI APK** ثم اضغط **Run workflow**.
4. بعد نجاح العملية افتح نتيجة التشغيل ونزّل الملف من قسم **Artifacts** باسم `omni-android-apk`.
5. فك ضغط الملف وستجد `app-release.apk`.

يعمل الـ workflow على إنشاء ملفات Android، وإضافة أذونات الإنترنت والكاميرا، ثم تثبيت الحزم وبناء APK.

## البناء محلياً

يتطلب Flutter stable وAndroid SDK:

```bash
flutter create --platforms=android --org com.omni.toolbox --project-name omni .
python3 scripts/configure_android.py
flutter pub get
flutter analyze
flutter build apk --release
```

## ملاحظات مهمة

- لم يتم تضمين أي خدمة ذكاء اصطناعي في هذه النسخة.
- الملاحظات والمهام والمصاريف وسجل الأسعار تُحفظ محلياً على الجهاز عبر SharedPreferences؛ لا تستخدمها لتخزين بيانات شديدة الحساسية.
- أسعار العملات لا تُجلب تلقائياً. أدخل سعر الصرف الذي تتحقق منه بنفسك.
- سجل الأسعار يدوي وليس أداة كشط تلقائي لمواقع المتاجر.
- الطقس ومختصر الروابط يحتاجان اتصالاً بالإنترنت ويستخدمان خدمات خارجية.
- ملفات المستخدم لا تُرفع إلى خادم من داخل تطبيق OMNI.
- قارئ PDF ومستعرض الملفات يعملان عبر منتقي ملفات Android.
- صلاحية الكاميرا مطلوبة فقط عند اختيار مسح QR/الباركود.
- هذا إصدار تأسيسي يحتاج اختباراً على أجهزة Android فعلية قبل اعتباره إصداراً نهائياً.

## حالة النسخة الحالية

هذه حزمة مصدر أولية مع مسار بناء آلي. لم أتمكن من إنتاج APK داخل بيئة العمل الحالية لعدم توفر Flutter/Android SDK فيها، لذلك يجب تشغيل GitHub Actions للحصول على ملف APK، ثم اختباره على هاتف Android قبل اعتماده.

## الحزم الأساسية

- Flutter Material 3: بنية التصميم الأساسية.
- `flutter_animate`: حركات انتقال بسيطة.
- `lucide_icons_flutter`: مجموعة أيقونات Lucide.
- `shared_preferences`: تخزين الإعدادات والبيانات البسيطة محلياً.
- `mobile_scanner` و`qr_flutter`: المسح والإنشاء لرموز QR والباركود.
- `pdfrx` و`file_picker`: فتح ملفات PDF واختيار الملفات.
- `http`: الاتصال بخدمات الطقس واختصار الروابط.

راجع تراخيص كل حزمة قبل توزيع نسخة تجارية.
